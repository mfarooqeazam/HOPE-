## about.html

**certificate number discrepancy**

> Verify before launch. The CV lists the certificate number as #154629434; the certificate PDF reads IBA_072025_002612. The certificate's own number is used here &mdash; confirm which is correct. If the IBAO publishes a registry entry, link it: a number a visitor can check independently is worth far more than one they cannot. IBAO registry / verification URL

**reviews: ship empty rather than fabricated**

> Ship without this if it isn't ready. An empty reviews section is honest; a fabricated one is fraud and is trivially detectable. A short video testimonial carries more weight than any three written ones.

**photography consent (about gallery)**

> Consent first. Written consent is required for any identifiable child. Where you don't have it, photograph hands, materials or the room &mdash; never blur a face, it reads as concealment.

## training.html

**training: publish hours, dates, fees**

> This audience abandons on vagueness. Professionals comparing providers want hours, dates, fees and prerequisites before they enquire — not after. Filling the boxes above is the single highest-value change to this page.
