# Placeholder photography — REPLACE BEFORE LAUNCH


These are **placeholders**, not photographs of this centre. Every frame on the
site carries a visible `placeholder` badge, and the project rule stands: no
fabricated impression that these are HOPE's own rooms, staff or children.

They were re-sourced from **Wikimedia Commons** (via the Openverse search API)
so that the people in them are from Pakistan, India and the wider
subcontinent, rather than the Western stock imagery that shipped before. The
brief for each slot is unchanged — the filename still names the slot and the
photograph that eventually has to replace it.

## Licensing — read this before launch

Every file below is either public domain or Creative Commons. The CC BY and
CC BY-SA ones **require visible attribution wherever the image is published**.
This file satisfies that inside the repository; it does **not** satisfy it on
the deployed site. Before launch, either

1. replace these with the centre's own photographs — the intended outcome, and
   the reason each frame is badged as a placeholder; or
2. publish a credits page carrying the rows below and link it from the footer.

CC BY-SA additionally means a cropped or edited version of that photograph
stays CC BY-SA. Each file here has been resized and centre-cropped to fit its
frame, so that condition is live for every `by-sa` row.

## How to replace one

1. Drop your photograph in this folder with the **same filename**.
2. Make a 700px-wide copy named `<name>-sm.webp` (the `srcset` fallback).
3. Keep the same pixel dimensions, or update `width`/`height` in the markup —
   they are what keeps cumulative layout shift at zero.
4. When every frame in a section is real, delete `frame--comp` from that
   markup to remove the badge, and delete that row here.

Each file is used in exactly one place.
