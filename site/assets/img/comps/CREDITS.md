# Placeholder photography — REPLACE BEFORE LAUNCH

These are the design handoff's Unsplash comps, downloaded so the site can be
seen as designed. Free licence, commercial use permitted — but they are **not**
photographs of this centre, and the project rule is no stock photography of
children. Every frame on the site carries a visible `placeholder` badge.

## How to replace one

1. Drop your photograph in this folder with the **same filename**.
2. Make a 700px-wide copy named `<name>-sm.webp` (the `srcset` fallback).
3. When every frame in a section is real, delete `frame--comp` from that
   markup to remove the badge.

Each file is used in exactly one place. No image is repeated anywhere on the
site — if you swap one, only the page listed changes.
