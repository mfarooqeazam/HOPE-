# Assets — two files to save here

The homepage expects these two files in this folder. Until they're here, the logo shows
as the word "HOPE" and the certificate link won't open.

## 1. The logo → save as `hope-logo.png`

The HOPE logo you sent in chat — the wordmark with the tree and stars.

Save it into this folder with the **exact** filename:

```
hope-logo.png
```

Lowercase, with the hyphen. Filenames are case-sensitive on the web server even though
Windows doesn't care, so getting this right now avoids a broken image after launch.

**If you have the original vector file** (`.svg`, `.ai`, `.eps`, or a PDF from your
designer), that is much better than a PNG — it stays sharp at any size and on high-density
phone screens. Save it as `hope-logo.svg` and say so, and I'll switch the page to use it.

**If you only have a PNG:** make sure it has a *transparent* background, not white. The
header sits on warm cream, so a white-boxed logo will show as a visible rectangle.

## 2. The certificate → save as `ibao-certificate.pdf`

Your IBAO certificate, exactly as issued:

```
ibao-certificate.pdf
```

The page links to it so visitors can open the original rather than take the claim on
trust. That is what makes it a credential instead of a sentence.

### A note on publishing it

The certificate carries your full name and certification number. That's normal and
expected for a professional credential — it's the point of publishing one. Nothing else
on it is sensitive. But it is your decision to publish, so if you'd rather show only the
certification number without linking the PDF, say so and I'll remove the link.
